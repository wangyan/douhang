# 斗航（DouHang）管理指南

本文档面向系统管理员与已登录用户，全面介绍服务卡片录入、分类编排、实时小组件 (Widgets) 监控、外观与素材管理、全局配置以及数据备份恢复。

- **前台使用与访问**：请参阅[用户指南](./USER_GUIDE.md)
- **安装部署与运维**：请参阅[部署指南](./DEPLOYMENT.md)
- **系统架构与机制**：请参阅[架构文档](./ARCHITECTURE.md)
- **代码贡献与发版**：请参阅[贡献指南](./CONTRIBUTING.md)

## 1. 管理权限与界面概览

### 1.1 登录与口令安全

- **管理权限**：以管理员身份登录后，系统将解锁全量管理功能（包括卡片与分类编辑、小组件监控横条、全站外观定制、素材库管理与数据备份恢复）。
- **口令修改**：**初次登录系统后，请务必前往「设置 → 账号与安全」修改初始管理员密码**。修改密码后，所有既有登录会话将立即失效，需重新登录。

### 1.2 登录后的界面扩展

成功登录后，主页会解锁以下专属管理功能：
1. **小组件横条 (Widget Bar)**：时钟下方显现容器监控、系统资源与吞吐指标组件；
2. **悬浮工具栏扩展**：新增组件显隐开关、画布编辑模式（铅笔图标）以及批量删除模式；
3. **用户菜单扩展**：右上角用户菜单新增「外观快捷面板」与「系统设置」后台入口。

## 2. 服务卡片与分类管理

### 2.1 极速录入与添加卡片

点击分类标题右侧的 **＋** 按钮即可打开卡片新建弹窗。同时系统支持多种极速录入方式：

1. **外部超链接拖拽录入**：
   从任意浏览器标签页、收藏夹或其他网页中，将链接直接拖拽至斗航（DouHang）窗口，页面高亮提示「松开以添加卡片」后释放，系统会自动打开弹窗并解析预填标题与 URL。
2. **剪贴板快捷粘贴**：
   在主页空白区域直接按下快捷键 `⌘ / Ctrl + V`，若剪贴板内包含有效 URL，系统将自动唤起创建弹窗并预填内容。
3. **图标解析与匹配**：
   - **自动抓取 Favicon**：输入网址后系统会在后台自动探测该站点的最高清 Favicon 图标并持久化缓存至本地；
   - **内置图标库**：内置 275+ 个主流开发运维工具、开源应用与云原生服务官方矢量图标，支持中文拼音与英文快速检索；
   - **自定义本地上传**：支持直接上传本地 PNG、JPG、WebP 或 SVG 图像作为卡片图标。

### 2.2 内外网双地址与自适应策略

每张卡片均支持配置独立的**内网地址**与**外网地址**：

- **自动探测（推荐）**：系统在后台以毫秒级速度探测目标地址可达性。在内网直连环境下自动走内网 IP 或端口，外网访问时自动切换至公网域名或内网穿透地址；
- **固定策略**：管理员亦可在「设置 → 通用」中全局强制指定为「仅内网模式」或「仅外网模式」。

### 2.3 打开方式与模态弹窗 (Iframe) 配置

- **新标签页打开**（默认）：点击卡片在新标签页开启目标应用；
- **模态弹窗嵌入 (Iframe)**：适用于文档知识库、Grafana 看板或轻量管理界面。用户可在当前页面内直接内嵌操作。
  - **尺寸记忆**：拖拽弹窗右下角手柄可任意设定宽高，系统会自动为该卡片记录最佳窗口大小；
  - **安全策略排错**：若目标服务配置了严格的 `X-Frame-Options: DENY` 或 `Content-Security-Policy: frame-ancestors`，浏览器会拦截 Iframe 渲染。此时需在目标服务或反向代理配置中放行嵌入。

### 2.4 在线健康检查与状态指示灯

卡片右上角配备状态指示灯，系统每 60 秒自动发送探活请求：
- **实心绿点**：服务在线且网络连通正常；
- **空心红环**：服务离线、端口未监听或网络不可达；
- 若无需展示，可在「外观快捷面板」或「设置 → 外观」中随时停用状态灯显示。

## 3. 画布编辑、排序与批量操作

点击右上角悬浮工具栏的**铅笔图标**即可进入编辑模式：

### 3.1 自由拖拽排序

- **卡片自由排序**：在同分类内直接拖拽卡片调整展示次序；
- **跨分类移动**：将卡片拖动到其他分类容器中实现分类归属变更；
- **空分类容器拖入**：即使某个分类下当前没有任何卡片，亦可直接将卡片拖入空容器内。

### 3.2 分类管理

- 在「设置 → 分类」中可新建分类、配置色彩标识（十六进制颜色值）与专属分类图标，并拖拽编排分类展示先后顺序；
- 在编辑模式下，点击分类标题旁的删除按钮即可快捷删除分类。**分类删除后，其下的所有卡片会自动安全归入「未分类」分组，绝不丢失卡片数据**。

### 3.3 批量删除与撤销保护

- 在编辑模式下再次点击铅笔图标，即可进入**批量删除模式**；
- 在卡片网格中勾选多个目标卡片，点击屏幕底部的「删除所选」即可完成批量清理；
- **防误触撤销机制**：执行删除后，屏幕底部将弹出提示条，**5 秒内点击「撤销」即可无损还原所有被删卡片**；
- 随时按下键盘 `ESC` 键即可退出编辑或批量删除模式。

## 4. 实时监控小组件 (Widgets)

登录状态下，时钟下方常驻小组件横条。支持根据监控需求添加多个同类组件实例，每个实例均可独立配置参数与展示规格（S / M / L 尺寸）：

| 组件名称 | 核心监控能力与说明 | 刷新周期 |
|---|---|---|
| **Docker / 容器状态** | 直连 Docker Engine API，实时监控运行中、已停止容器总数及关键核心容器运行状态 | 实时直连 |
| **系统资源水位** | 实时采集宿主机 CPU 利用率、物理内存占用百分比与当前磁盘 I/O 速率 | 5 秒 |
| **qBittorrent 监控** | 实时下载/上传传输速率、累计流量统计、活跃任务与做种数、磁盘剩余可用容量 | 10 秒 |
| **倒数日** | 追踪重大版本发布、证书到期或账期结算剩余天数，支持按周/月/年周期循环 | 每日 |
| **正数日** | 记录项目启动日期、系统稳定连续运行天数计数（从设定基准日期起算） | 每日 |

### 4.1 qBittorrent 监控组件配置指南

1. **添加与凭据配置**：
   添加组件后点击齿轮进入设置，填写 qBittorrent WebUI 访问地址（推荐填写内网 `http://<IP>:<端口>`）以及登录用户名和口令。
2. **密码脱敏保护**：
   口令存储在本地安全设置中，再次编辑组件时密码框保持留空即表示沿用既有凭据。
3. **常见连接排错**：
   - **反向代理 Host 拦截**：若 qBittorrent 位于反向代理之后，务必在 qB 的「Web UI」设置中取消勾选「启用 Host header 属性验证」；
   - **防爆破安全保护**：若密码配置错误，系统会自动启用指数退避策略并在连续失败 3 次后主动暂停轮询，防止触发 qBittorrent 的 IP 防爆破封禁策略。

## 5. 全局管理后台（「设置」页）

从主页用户菜单进入「设置」。桌面侧栏分为「站点」「内容」「系统」三组；移动端通过分区菜单切换。后台不显示首页浮动工具栏，返回首页与退出登录入口分别位于侧栏顶部和底部，移动端位于页首。

开关与选项修改后立即保存，结果通过通知提示；品牌、用户名与密码表单仅在有改动时显示「撤销 / 保存」操作栏。

### 5.1 通用
- **品牌**：修改站点标题、Logo 及其显示开关，确认后保存；
- **网络模式**：设置默认网络策略（自动探测 / 仅内网 / 仅外网），切换后立即保存。

### 5.2 外观与快捷面板
- **主题与字号**：选择明亮、暗黑或跟随系统，调整界面字号；
- **卡片显示**：设置显示密度、简洁模式、可达状态点与 Widget 横条；
- **壁纸**：点击缩略图立即应用，通知提供「撤销」；可上传自定义图片并调整遮罩强度，图片删除在素材页管理；
- **外观快捷面板**：主页用户菜单中的「外观」提供同一套设置。游客修改仅保存在当前浏览器。

### 5.3 分类
- 管理首页卡片分组，支持创建、编辑、删除与拖拽排序；
- 分类名称旁显示卡片数量，删除前确认卡片的处理方式。

### 5.4 搜索
- 管理搜索框可用的搜索引擎，支持添加自定义网址模板、编辑与拖拽排序；
- 默认搜索源以界面标记为准，至少保留一个引擎。

### 5.5 素材
- 集中管理上传的卡片图标与壁纸，支持搜索、排序与网格 / 列表切换；
- **引用统计**：查看文件使用情况；
- **批量清理**：勾选素材后确认删除，当前使用中的壁纸受到保护。

### 5.6 账号与安全
- **用户名**：修改后保存，下次登录生效；
- **修改密码**：验证当前密码，输入不少于 8 位的新密码并确认；可切换密码的显示与隐藏，修改后既有会话失效。

### 5.7 数据与备份
- **导出备份**：下载站点数据及上传的图标与壁纸，不包含登录账号与密码；
- **危险操作**：从备份恢复会覆盖当前全部数据，上传后需再次确认，操作前建议导出备份。

### 5.8 关于
- **项目链接**：直达项目主页、容器镜像、管理指南与部署文档；
- **版本更新**：开启或关闭自动检查，关闭后仍可手动检查；国内网络环境可开启 AtomGit 加速，发现新版本时提供升级命令；
- **更新日志**：浏览内置版本亮点或完整发布记录；
- **运行环境**：查看当前版本、Node.js 运行时与平台架构。

## 6. 数据安全与备份迁移

斗航（DouHang）采用完全本地化的数据架构，所有卡片定义、分类排版、组件配置与自定义资产均保存在本地持久化目录（`./data`）中。

### 6.1 一键整包备份（推荐）

进入「设置 → 数据与备份」：
- 点击「导出备份」，系统将把全量数据库表数据（`backup.json`）与上传素材目录（`uploads/`）完整打包为一个标准的 `.zip` 压缩文件下载至本地；
- 建议在服务器系统重装、版本升级或关键配置变动前执行导出备份。

### 6.2 迁移与数据恢复

- **全量无损还原**：在全新部署的实例中，进入同一界面上传 `.zip` 备份文件，系统会自动校验解压并写入数据库与素材目录，实现 100% 原样还原；
- **纯结构导入**：若只需同步卡片与分类结构而不需要历史上传素材，亦可单独上传 `backup.json` 纯文本文件进行快速恢复。
