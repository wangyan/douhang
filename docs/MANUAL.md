# 斗航使用手册

本文档面向日常使用者，全面介绍斗航（DouHang）各项功能的使用方式、快捷操作与进阶技巧。系统部署与运维详见[部署文档](./DEPLOYMENT.md)；技术实现见[架构文档](./ARCHITECTURE.md)。

---

## 1. 认识斗航

斗航是一个面向工作台与私有云环境的**自托管服务导航起始页**。它将散落在私有网络、局域网与公网中的各类服务（如代码仓库、知识库、项目看板、监控面板、内部控制台等）整理为清晰直观的卡片，配合容器运行状态监控、内外网地址智能切换与全局快速搜索，让你的浏览器首页成为高效的一站式工作台。

| 核心特性 | 体验亮点 |
|---|---|
| **智能卡片导航** | 分类归集，支持拖拽排序、批量删除、在线状态检测与弹框免跳转打开 |
| **内外网无感切换** | 智能探测网络连通性：办公/内网环境走直连，公网环境走安全域名或反向代理 |
| **实时小组件 (Widget)** | 监控 Docker 容器运行状态、系统资源水位、吞吐监控与重要日程 |
| **拼音全局搜索** | `⌘ / Ctrl + K` 瞬间唤起，支持拼音全拼、首字母缩写与子串匹配 |
| **外观与快捷面板** | 免进设置页随时切换明暗主题、字号、卡片简洁模式与精美壁纸 |
| **访客友好体验** | 首页支持免登录公开浏览与搜索，敏感小组件与管理功能仅登录后可见 |
| **移动端与 PWA 支持** | 支持安装至手机/桌面主屏，提供静态资源本地离线缓存与断网兜底 |
| **一键完整备份** | 站点配置与上传的壁纸、图标一键打包为 zip，随时无损迁移恢复 |

## 2. 快速上手

### 2.1 登录与权限角色

- **管理员态**：输入部署时配置的账号口令登录后，拥有全局管理权限（卡片增删改、小组件增删改、外观定制、站点配置与备份恢复）。**首次登录后请立即前往「设置 → 通用」修改默认口令**。
- **访客态（未登录）**：直接访问首页无需登录，可正常浏览卡片、使用全局搜索与搜索引擎跳转；所有小组件模块、编辑功能与管理后台均自动隐藏，安全保护私有信息。

### 2.2 常用快捷键与操作速查

| 操作 / 快捷键 | 触发场景 | 交互效果 |
|---|---|---|
| `⌘ / Ctrl + K` | 任意页面 | 唤起全局卡片搜索面板 |
| `⌘ / Ctrl + V` | 首页空白处 | 将剪贴板中的 URL 直接创建为新卡片 |
| **拖拽链接到页面** | 浏览器地址栏 / 网页超链接 | 拖入后释放，直接打开新建卡片并预填信息 |
| `ESC` 键 | 批量删除 / 编辑模式 | 逐层退出当前模式，回到常规视图 |
| **卡片右键菜单** | 任意服务卡片 | 唤起快捷菜单（编辑 / 弹框打开 / 复制地址 / 删除） |
| **长按卡片** | 触屏 / 移动设备 | 唤起移动端底部操作抽屉 |

## 3. 主页布局与悬浮工具栏

主页自上而下由四大核心区域构成：
1. **品牌与时钟区**：左上角常驻品牌标识，居中展示实时数字时钟。
2. **多引擎搜索栏**：集成主流搜索引擎与卡片直达入口。
3. **Widget 小组件栏**（仅登录展示）：展示容器概览、系统资源水位、吞吐监控与重要日程。
4. **分类服务卡片区**：按业务或系统维度归集的导航卡片网格。

### 悬浮工具栏 (Floating Toolbar)

右上角常驻胶囊型悬浮工具栏，提供沉浸式快捷操作：

- **搜索图标**：点击唤起全局卡片搜索（等同于 `⌘/Ctrl + K`）。
- **紧凑视图开关**（图标列表）：一键在「标准视图」与「简洁模式」之间切换。
- **主题切换**（太阳/月亮）：一键快速切换明亮、暗黑或跟随系统。
- **Widget 横条显隐**（网格图标，登录后可见）：临时折叠或展开小组件模块。
- **编辑模式**（铅笔图标，登录后可见）：点击进入画布编辑模式，再次点击进入批量删除模式。
- **用户菜单**（头像/齿轮，登录后可见）：
  - **外观**：打开贴边「外观快捷面板」，就地调节主题、字号、壁纸与状态指示灯。
  - **设置**：跳转进入完整管理后台。
  - **使用手册**：直达本手册页面。
  - **关于**：查看当前版本号与官方更新动态。
  - **退出登录**：安全退出当前会话。

## 4. 卡片与分类管理

### 4.1 快速添加卡片

点击分类标题右侧的 **＋** 按钮，或者使用以下高效率方式：

1. **拖拽网页链接**：从浏览器标签页、收藏夹或其它网页中将链接拖拽至斗航窗口，页面会亮起「松开以添加卡片」提示，松手后自动打开卡片弹窗并预填标题与 URL。
2. **剪贴板直接粘贴**：在主页任意空白处直接按下 `⌘ / Ctrl + V`，若剪贴板内为有效链接，将自动打开创建弹窗并预填。
3. **图标智能解析**：
   - **自动抓取 Favicon**：输入地址后自动探测网站高分图标并持久化缓存。
   - **内置图标库**：内置 275+ 个主流开发运维工具、云原生服务与自托管应用官方图标（支持拼音与英文搜索）。
   - **本地上传**：支持上传自定义 PNG、JPG、WebP 或 SVG 图像。

### 4.2 内外网地址与智能自适应

每张卡片均支持独立填写**内网地址**与**外网地址**：

- **自动探测（推荐）**：系统在后台以毫秒级速度探测地址可达性。在局域网内优先直连高速内网；在外网或蜂窝网络下，自动降级跳转至公网域名或内网穿透地址。
- **固定模式**：可在「设置 → 通用」中全局锁定为仅内网或仅外网模式。

### 4.3 打开方式：新标签页与内置弹框

- **新标签页**（默认）：点击卡片在新标签页开启目标应用。
- **弹框嵌入 (Iframe)**：直接在当前页面以内置模态弹窗方式打开服务（如文档知识库、监控看板或轻量运维工具）。
  - 右下角配备拖拽手柄，可自由调整弹窗宽高，系统会自动保存您的最佳窗口尺寸。
  - 打开前会自动预检目标站点的同源嵌入策略（`X-Frame-Options` / `CSP`），若目标站点限制嵌入，右键菜单中仍保留在新标签页打开。

### 4.4 卡片状态灯 (Health Check)

每张卡片右上角配有状态指示灯，每 60 秒自动探测连通性：
- **实心绿点**：服务在线，连接通畅。
- **空心红环**：服务离线或网络不可达。
- 探测失败或未知时不显示标记，避免视觉干扰。可在「外观设置」中随时开启或关闭状态灯。

### 4.5 编辑模式、排序与分类管理

点击工具栏铅笔图标进入**编辑模式**：

- **卡片自由拖拽**：在分类内部或跨分类拖动卡片调整次序。
- **空分类拖入**：即使分类下没有任何卡片，也可以直接将卡片拖入空分类容器中。
- **分类管理**：
  - 在「设置 → 分类」中可新建分类、设置专属图标与色彩标识、拖拽调整分类展示顺序。
  - 编辑模式下点击分类标题旁的删除按钮即可快捷删除分类，分类下的卡片会自动安全归入「未分类」，绝不丢失。
- **批量删除与防误触撤销**：
  - 二次点击编辑按钮可进入批量删除模式，勾选多个卡片后一键清理。
  - 删除操作具备**可撤销机制**：误删后屏幕下方会弹出撤销提示条，5 秒内点击「撤销」即可无损恢复。
- **快捷退出**：随时按下键盘 `ESC` 键即可退出编辑或批量模式。

## 5. Widget 小组件

登录状态下，主页展示高度可定制的小组件横条，同类组件可重复添加，每个实例均支持独立配置与尺寸调节（S / M / L）：

| 组件名称 | 核心指标与功能说明 | 刷新周期 |
|---|---|---|
| **NAS / 容器状态** | 汇总 Docker 容器运行状态（运行中 / 已停止 / 容器总数）及关键容器名 | 实时直连 |
| **资源水位** | 服务器 CPU 使用率、内存占用、实时磁盘读写速率 | 5 秒 |
| **qBittorrent** | 对称双英雄速率（下载/上传实时吞吐）、历史累计上传/下载量、做种与活动数、磁盘剩余空间 | 10 秒 |
| **倒数日** | 追踪重要里程碑、项目发布或周期结算剩余天数，支持周/月/年周期重复 | 每日 |
| **正数日** | 记录项目启动节点、系统连续稳定运行天数（从指定日期起算） | 每日 |

### 5.1 qBittorrent 组件配置指南

1. **添加与设置**：添加组件后点击「设置」，填写 qB WebUI 访问地址（推荐填写内网 IP:端口）及登录用户名、密码。
2. **密码脱敏保护**：密码经过安全脱敏处理，再次编辑时密码框留空即表示沿用已存凭据。
3. **网络与跨域排错**：
   - 若 qB 处于反向代理之后，需在 qB 设置中取消勾选「启用 Host header 属性验证」。
   - 若密码错误，系统会自动启用指数退避并在连续失败 3 次后主动暂停轮询，防止触发 qB 的防爆破封禁策略。

## 6. 全局搜索与快捷启动

### 6.1 卡片全局秒搜 (`⌘ / Ctrl + K`)

按下键盘快捷键 `⌘ / Ctrl + K`（Mac）或 `Ctrl + K`（Windows），即可唤起全局 Command 面板：
- **子串匹配**：输入 `git` 匹配 `GitLab`。
- **拼音首字母缩写**：输入 `bf` 秒出「备份与恢复」。
- **全拼匹配**：输入 `cangku` 匹配「代码仓库」。
- 键盘上下键选中目标，回车即可立刻直达。

### 6.2 多引擎网页搜索

顶部主搜索框支持作为外网搜索引擎入口：
- 点击搜索框左侧的引擎图标，可在百度、Google、Bing、DuckDuckGo 等主流引擎之间秒切。
- 支持在「设置 → 搜索」中添加内网搜索（如 Everything、内网 Wiki）或自定义搜索引擎，并支持拖拽调整常用顺序。

## 7. 外观与个性化定制

### 7.1 贴边外观快捷面板

无需跳转设置页！点击右上角用户菜单中的「外观」，即可拉出贴边抽屉：
- **主题模式**：一键切换明亮、暗黑或随系统自动变换。
- **字号缩放**：提供标准、舒适、大字号多种排版比例，适配 4K 大屏或客厅电视浏览。
- **视图切换**：开启「卡片简洁模式」（隐藏副标与辅助说明，卡片更小巧紧凑）。
- **状态灯开关**：按需开启或隐藏卡片在线指示灯。
- **壁纸与遮罩浓度**：直接在面板内切换预设壁纸或调整半透明磨砂遮罩浓度。

### 7.2 素材库中心

在「设置 → 素材」中集中管理全站视觉资源：
- 集中查看所有本地上传的卡片图标、品牌 Logo 与壁纸高清图。
- 实时统计每个素材的**引用计数**，清晰标注哪些文件处于闲置状态，支持一键安全清理冗余文件，释放空间。

## 8. 数据安全与备份恢复

斗航采用完全本地化的存储架构，所有数据均保存在本地 SQLite 数据库与素材目录中。

### 8.1 一键完整备份

进入「设置 → 通用 → 备份」：
- **导出数据包**：点击「导出备份」，系统将把整个数据库配置（卡片、分类、组件、首选项）与上传的所有自定义素材完整打包为 `.zip` 文件下载。

### 8.2 迁移与数据恢复

- **全量无损恢复**：在新设备或重新部署的容器中，直接上传 `.zip` 备份文件，卡片、配置及图像资产将 100% 原样还原。
- **纯配置恢复**：同时支持上传单 JSON 配置文件快速还原卡片与分类结构。

## 9. 移动端体验与 PWA 安装

斗航为触屏设备与移动端进行了深度适配：

- **安装至主屏幕 (PWA)**：
  - **iOS**：使用 Safari 打开斗航，点击底部「分享」按钮，选择「添加到主屏幕」。
  - **Android / 桌面端**：在 Chrome 或 Edge 菜单中点击「安装应用」或地址栏右侧的安装图标。
  - 安装后支持独立全屏窗口运行，无浏览器地址栏干扰，如同原生 App。
- **静态资源离线缓存**：Service Worker 自动在本地缓存前端脚本、字体与核心样式，二次打开速度显著提升。
- **断网友好兜底**：当遇到完全断网时，展示专门优化的离线等待页面，网络恢复后自动无缝重连。
- **移动端手势**：卡片支持长按唤起操作抽屉，组件栏在小屏幕上自动折叠为单列流式布局。
