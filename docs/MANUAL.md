# 使用手册

本文档面向使用者，说明界面各项功能的使用方式。安装与部署见[部署文档](./DEPLOYMENT.md)；系统结构见[架构文档](./ARCHITECTURE.md)。

## 1. 认识斗航

斗航是一个部署在自有 NAS 上的**导航起始页**。它将 qBittorrent、Jellyfin、Alist 等自托管服务整理为卡片，配合容器状态监控与内外网地址自动切换，点击卡片即可直达目标服务。

| 功能 | 说明 |
|------|------|
| 卡片化导航 | 分类组织，支持拖拽排序与批量管理 |
| Widget 栏 | NAS 状态、资源水位、qBittorrent、倒数日 / 正数日，实例化自由组合 |
| 内外网自动切换 | 网络策略自动选择可达地址：内网环境走内网地址，外网环境走外网地址 |
| 拼音全局搜索 | `⌘ / Ctrl + K` 唤起，支持拼音和首字母缩写匹配 |
| 备份 / 恢复 | 一键导出 zip，配置和上传文件完整带走 |

## 2. 快速上手

**前提**：斗航已完成部署并可访问。部署方式见[部署文档](./DEPLOYMENT.md)。

### 登录

登录账号与初始密码由部署时的 `.env`（`AUTH_USERNAME` / `AUTH_PASSWORD`）决定，具体见[部署文档](./DEPLOYMENT.md)。**登录后请立即前往「设置 → 通用」修改密码**；修改密码后所有既有会话立即失效，需要重新登录。

### 基本操作速查

| 操作 | 效果 |
|------|------|
| `⌘ / Ctrl + K` | 全局搜索卡片 |
| 顶部搜索框 | 输入任意关键词回车，直接跳转当前选中的搜索引擎 |
| 右上工具栏「编辑」按钮 | 进入编辑模式，可拖拽卡片 / 分类，二次点击进入批量删除 |
| 右上工具栏「主题」按钮 | 明暗主题切换 |
| 右上用户菜单「关于」 | 查看版本号与更新日志 |
| Widget 栏 ＋ 按钮 | 添加新的 Widget 实例 |
| 卡片右键菜单 | 编辑卡片 / 弹框打开 / 复制 URL / 删除卡片 |
| 卡片右上状态灯 | 60 秒轮询刷新，显示在线（实心绿点）/ 离线（空心红环），未知状态不显示标记；可在「设置 → 外观」关闭 |

## 3. 主页总览

主页自上而下分为四个区域：**品牌与时间**、**全局搜索框**、**Widget 栏**和**分类卡片区**。Widget 栏横贯首屏，网格按宽度在四列 / 两列 / 单列间自动切换。

检测到新版本时，右下角出现更新提醒，可直接展开当次更新日志或前往发布页；关闭提醒后，右上工具栏保留一个常驻入口，点击即为「关于」弹窗中的新版提示。

## 4. 卡片与分类

### 添加卡片

点击分类标题旁的 **＋** 新建卡片，填写名称与地址即可。图标有三种来源：

1. **自动抓取 favicon** —— 填完地址自动尝试获取网站图标
2. **内置图标库** —— 275 个精选自托管服务图标，支持搜索
3. **本地上传** —— 上传自定义图片

### 拖入 / 粘贴快速创建

把浏览器地址栏的 URL、书签或网页中的链接直接拖到斗航页面上，会出现「松开以添加卡片」的放置提示；松手后自动打开新建卡片弹框并**预填地址**。也可以在页面上直接 `⌘ / Ctrl + V` 粘贴链接，效果相同。两种方式都会**优先抓取网站标题作为卡片名称**，抓取失败时回退为域名，指定分类后保存即可。

- 仅识别 http/https 链接
- 拖入文件（如图标上传）不受影响
- 与编辑模式下的卡片排序拖拽互不干扰

### 卡片地址与内外网

每张卡片可以同时配置**内网地址**和**外网地址**。网络策略设为「自动」时，斗航会探测哪个地址可达并优先跳转；也可以在「设置 → 通用」固定为内网或外网模式。

### 卡片打开方式

编辑卡片时，「打开方式」分段选择决定点击行为：

- **新标签页** —— 默认，在新标签页打开目标站点
- **弹框** —— 在当前页以 iframe 弹框打开，右下角手柄可拖拽调整宽高，尺寸自动保存

弹框打开前会预检目标站点的嵌入限制，若目标站点拒绝嵌入，可改用「新标签页」方式打开。无论卡片设置了哪种方式，右键菜单始终有「弹框打开」入口。

### 分类管理

「设置 → 分类」中可以新建、重命名、拖拽排序分类，删除分类时其中的卡片会自动移入「未分类」。

### 空状态

还没有任何卡片时，主页会显示空状态引导——「开始搭建你的导航台」，点其中的「创建卡片」即可打开新建卡片弹框，新卡片默认归入「未分类」。

添加第一张卡片后，空状态会自动消失。

## 5. 全局搜索

按 `⌘ / Ctrl + K` 唤起全局搜索，对卡片名称、地址与描述执行匹配。匹配规则有三种：**子串**（不区分大小写，输入「jelly」能找到「Jellyfin」）、**拼音首字母缩写**（输入「bf」能找到「备份」）、**拼音全拼**（输入「beifen」能找到「备份」）。拼音匹配对中文名生效。

顶部搜索框则是**搜索引擎跳转入口**：输入非卡片关键词回车，直接用当前选中的引擎搜索。引擎可以在「设置 → 搜索」中增删改和排序。

## 6. Widget 小组件

Widget 栏支持 5 种小组件，**同类可重复添加、每个实例独立配置**，支持调整大小和拖拽排序：

| Widget | 说明 |
|--------|------|
| NAS 状态 | Docker 容器运行状态总览（在线 / 停止 / 总数） |
| 资源水位 | CPU / 内存 / 磁盘 IO 实时水位，5 秒自动刷新 |
| qBittorrent | 下载/上传速度、做种统计与剩余空间，10 秒自动刷新 |
| 倒数日 | 距离未来的重要日子还有几天，每个实例维护一个日期项，可设每周 / 每月 / 每年重复 |
| 正数日 | 过去的重要日子已经过去了多少天 |

日期项采用日历日语义，选择哪天就显示哪天。

> Docker 数据通过挂载的 `docker.sock`（或 `DOCKER_HOST`）获取；不可用时 Widget 会降级显示，不影响其他功能。

**qBittorrent 配置说明**：

- 添加时未配置连接会就地填写表单，右键 Widget「设置」可随时修改，保存时自动验证连接
- 填写 qB WebUI 根地址与账号密码（与浏览器登录 qB 相同）；生产部署推荐使用内网地址直连
- 走反向代理访问时，需关闭 qB 的「启用 Host header 属性验证」，并确保代理未拦截 `/api/` 请求
- 登录失败会自动退避重试，连续失败 3 次暂停以避免触发 qB IP 封禁；修正配置后在「设置」重新保存即可恢复
- 连接密码明文保存在配置中并随备份导出，请注意保管备份文件

## 7. 外观与壁纸

「设置 → 外观」提供主题切换（明亮 / 暗黑 / 跟随系统）、界面字体大小、卡片状态灯开关，以及自定义首页壁纸。

上传过的图标与壁纸统一在「设置 → 素材」中管理，可查看引用情况并安全清理。

## 8. 站点设置

「设置 → 通用」集中管理站点级配置：

- **品牌** —— 自定义站点标题与 Logo
- **账号 / 安全** —— 修改用户名与密码（修改密码后所有既有会话立即失效，需要重新登录）
- **网络** —— 网络策略：自动探测 / 固定内网 / 固定外网
- **版本更新** —— 自动检测新版本（每 24 小时查询一次），可关闭自动检测或随时「立即检查」

## 9. 备份与恢复

「设置 → 通用 → 备份」：

- **导出** —— 下载 zip 包，包含全部配置数据 + 上传的图标 / 壁纸文件
- **导入** —— 支持上传 zip 或裸 JSON，恢复到任意斗航实例

> 建议在变更配置或迁移环境前导出数据备份。

## 10. 部署

部署与数据持久化说明见[部署文档](./DEPLOYMENT.md)。

**安装到主屏（PWA）**：手机或桌面浏览器访问 DouHang 后，在浏览器菜单中选择「添加到主屏幕 / 安装应用」，即可像原生应用一样独立窗口打开；静态资源会本地缓存，二次打开更快。
