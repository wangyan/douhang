## 1. 产品简介

斗法领航（DouHang）是一款专为局域网、私有云与自托管环境设计的**服务导航起始页**。它将散落在局域网、内部系统或公网中的各类服务整理为清晰直观的分类卡片网格，提供免登录公开浏览、毫秒级智能内外网选路、拼音全局秒搜与开箱即用的沉浸式体验。

| 核心特性 | 能力说明 |
|---|---|
| **智能服务卡片** | 分类清晰归集，支持在线状态检测与弹窗内嵌浏览 |
| **内外网无感切换** | 智能探测网络连通性：办公与内网直连高速网络，公网环境走安全域名或反代 |
| **快捷全局搜索** | `⌘ / Ctrl + K` 瞬间呼出，支持拼音全拼、首字母缩写、中文子串与即时跳转 |
| **多引擎集成检索** | 顶部主搜索框集成主流搜索引擎，支持即时切换目标引擎与关键词跳转 |
| **个性化显示切换** | 免登录就地切换明暗主题、卡片简洁模式与网络工作模式（本地自动记录） |
| **移动端与 PWA 支持** | 支持安装至桌面或移动端主屏幕，具备本地静态资源缓存与断网重连保障 |

## 2. 界面布局与常用快捷键

### 2.1 主页核心区域

主页自上而下由三大核心区域构成：
1. **品牌与时钟区**：左上角常驻站点品牌标识，居中展示实时数字时钟。
2. **多引擎搜索栏**：集成主流搜索引擎切换与全局卡片直达入口。
3. **分类服务卡片区**：按业务、系统或常用维度分块展示的服务导航卡片网格。

### 2.2 常用快捷键速查

| 快捷键 / 操作 | 触发场景 | 交互效果 |
|---|---|---|
| `⌘ / Ctrl + K` | 任意页面 | 唤起全局卡片搜索面板 |
| `ESC` 键 | 搜索面板 / 弹框内嵌 | 关闭当前弹窗，返回主页视图 |
| **卡片右键菜单** | 任意服务卡片 | 弹出快捷菜单（新标签页打开 / 弹窗打开 / 复制直达地址） |
| **长按卡片** | 触屏 / 移动设备 | 呼出移动端操作抽屉 |

## 3. 服务卡片访问与交互

### 3.1 打开方式：新标签页与内置弹框

每张卡片均支持两种打开方式：

- **新标签页打开**（默认点击）：直接在浏览器新标签页中访问目标系统。
- **模态弹窗嵌入 (Iframe)**：在卡片右键菜单中选择「在弹框中打开」，即可直接在当前页面以内置弹窗形式浏览目标服务（非常适合查阅内部知识库、查看即时监控看板或轻量工具）。
  - **窗口尺寸记忆**：拖拽弹窗右下角手柄可任意调节宽高，系统会自动在本地记住该卡片的最佳窗口尺寸。
  - **安全兼容提示**：部分外部站点配置了同源保护策略（如 `X-Frame-Options` 或 CSP 限制嵌入），若目标站点无法正常嵌入，可使用右键菜单切换为新标签页打开。

### 3.2 卡片在线健康指示灯

每张服务卡片右上角配备了实时状态指示灯，系统每隔 60 秒自动探测一次连通性：
- **实心绿点**：服务当前在线，网络连接正常。
- **空心红环**：服务离线或网络不可达。
- 探测失败或未开启探测时不显示标记，避免产生多余视觉干扰。

### 3.3 内外网地址智能切换

系统具备智能网络探测能力，可根据你所处的网络环境自动选择最佳访问线路：
- **局域网 / 内网环境**：系统优先使用内网高速直连地址（如局域网 IP 或内网专属域名），获得极致响应速度；
- **公网 / 移动蜂窝网络**：当探测到内网不可达时，自动无缝切换至公网域名或内网穿透地址。
- **手动切换模式**：点击右上角悬浮工具栏中的网络图标（地球/局域网标识），可在「自动探测」、「仅内网」和「仅外网」三种模式间循环切换。系统会在本地浏览器缓存你的选择。

## 4. 全局搜索与快捷跳转

### 4.1 全局卡片搜索 (`⌘ / Ctrl + K`)

按下键盘快捷键 `⌘ / Ctrl + K`（Mac）或 `Ctrl + K`（Windows），即可呼出全局 Command 搜索面板：
- **拼音首字母匹配**：输入 `bf` 即可迅速定位到「备份与恢复」。
- **全拼匹配**：输入 `cangku` 即可匹配「代码仓库」。
- **关键词子串**：输入 `git` 即可匹配 `GitLab` 等卡片。
- 使用键盘上下方向键选择目标，按下回车键即可直达；按 `ESC` 随时退出搜索。

### 4.2 顶部多引擎搜索栏

页面顶部的搜索框不仅支持搜索卡片，还能作为全网搜索引擎使用：
- 点击搜索框左侧的搜索引擎图标，可在百度、Google、Bing、DuckDuckGo 等搜索引擎之间快速切换；
- 输入搜索内容后按回车，将自动在新标签页中打开目标引擎的搜索结果。

## 5. 外观与显示偏好

右上角常驻胶囊型悬浮工具栏，提供无需登录即可生效的显示调节：

- **主题模式切换**（太阳/月亮图标）：点击可循环切换明亮模式、暗黑模式或跟随操作系统外观；
- **卡片简洁模式**（布局图标）：开启后将隐藏卡片副标题与辅助说明，仅保留图标与标题，界面更加小巧紧凑；
- **工具栏折叠**：点击左侧箭头按钮可随时收起悬浮工具栏，保持全屏沉浸视感。

## 6. 移动端与 PWA 体验

斗法领航针对移动设备、平板与触屏终端进行了深度适配：

- **添加到主屏幕 (PWA 应用)**：
  - **iOS (iPhone / iPad)**：在 Safari 浏览器中打开斗法领航，点击底部「分享」按钮，选择「添加到主屏幕」；
  - **Android / 桌面端**：在 Chrome 或 Edge 菜单中点击「安装应用」或地址栏右侧的安装图标；
  - 安装后支持独立全屏窗口运行，无浏览器顶栏和底栏干扰，如同原生 App 般纯净流畅。
- **离线缓存与断网重连**：
  - Service Worker 会在本地持久化缓存静态脚本、核心样式与字体，极大缩短二次加载时间；
  - 当遭遇断网时，系统会自动呈现离线友好界面，待网络恢复后无缝自动重连。
- **触屏手势**：长按卡片可呼出底部操作抽屉，提供快速打开与链接复制选项。

## 7. 浏览器要求

建议使用以下内核或更高版本访问：

| 浏览器内核 | 建议版本 | 覆盖产品 |
|---|---|---|
| **Chromium** | **123+** | Chrome、Edge、Brave 及主流双核浏览器极速模式 |
| **Safari** | **17.5+** | macOS、iOS、iPadOS Safari |
| **Firefox** | **128+** | Firefox 及 ESR 长期支持版 |

使用未达到建议版本的浏览器访问时，系统自动跳转至离线引导页（`/outdated.html`），支持下载离线安装包或跳过提示直接访问。
